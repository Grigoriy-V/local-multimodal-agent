# Version 1.5 step 5 — deterministic web verifier

## Outcome

Added a UI-independent `WebVerifier` that reads only a configured target inside
the active task grant and returns the graph's existing structured `TestReport`.
It performs four stable checks:

1. target file presence;
2. standalone HTML structure with doctype, head, body, canvas and inline script;
3. JavaScript syntax through `node --check -`, which parses but does not execute
   the artifact;
4. observable Snake control signals: 2D canvas, keydown handler, all four arrow
   directions and a timed or animation-frame game loop.

Missing or malformed artifacts produce a complete failed report rather than a
success claim or an unstructured exception. The target path is resolved again
inside the active task grant before it is read.

## Boundaries

The verifier proves static structure, JavaScript parseability and required code
signals. It does not execute the page, observe canvas pixels, advance time or
send keyboard input. Those behavioral claims remain reserved for the browser
verifier in Version 1.5 step 7.

No model request, GPU work, server restart, network request or external mutation
was performed.
