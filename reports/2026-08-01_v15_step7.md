# Version 1.5 step 7 — browser verifier

## Outcome

Added a UI-independent behavioral verifier to the task harness. The task grant
now names `browser_verify` separately from filesystem mutation. After the cheap
static gate passes, `LayeredWebVerifier` launches an already installed Edge or
Chrome process with a fresh temporary profile and controls it over the local
DevTools protocol.

The browser receives the generated HTML as an in-memory `data:` document. HTTP,
HTTPS, FTP and `file:` requests are blocked, so model-generated code cannot use
the verifier to read other local files or reach the network. External script
references also fail the static standalone-document check.

The browser report records:

1. successful page load;
2. runtime exceptions and error-level console/log entries;
3. a present, non-blank multi-color canvas;
4. a changed canvas fingerprint across timed frames;
5. delivery of a real `ArrowRight` key event;
6. creation of a PNG preview inside the active task grant.

The preview path is merged into `TaskOutcome.artifacts`, ready for any UI
adapter. Displaying task outcomes in Chainlit remains Version 1.5 step 9 rather
than placing task logic in the current conversational UI.

## Product smoke

The retained `workspace/snake.html` passed the four static and six browser
checks in installed Edge 150.0.4078.105. The browser observed time-based canvas
changes after keyboard input, reported no console errors and wrote
`workspace/snake-preview.png` (10,455 bytes). The combined probe completed in
approximately 2 seconds.

## Boundaries

Canvas movement is detected from frame fingerprints; this proves visible change,
not full game-rule correctness. Keyboard instrumentation proves delivery to the
page, while the static gate proves that all four Snake directions are represented
in code. The honest live Gemma acceptance run is deliberately separate in step
8 and will start from an empty sandbox without scripted responses or a seeded
defect.

No model request, inference GPU work, browser download, network request, server
restart or external mutation was performed. One short local headless Edge
process was started and stopped for each real browser check.
