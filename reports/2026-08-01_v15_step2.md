# Version 1.5 step 2 — bounded task graph

**Date:** 2026-08-01

## Result

Added a separate LangGraph task lifecycle with named nodes and routes:

`task -> plan -> implement -> test -> evaluate -> retry/finalize`

The conversational graph remains unchanged. The task graph stores only
inspectable working state: the task, concise plan, explicit steps, acceptance
criteria, implementation summary, structured check results, evaluation
feedback, counters and final outcome. It has no field for private
chain-of-thought.

The harness enforces:

- a maximum number of implementation iterations;
- a maximum number of reported tool calls, with the remaining allowance passed
  into each implementation attempt;
- a wall-clock deadline that cancels a slow asynchronous stage;
- honest stopped outcomes for empty tasks and exhausted budgets.
