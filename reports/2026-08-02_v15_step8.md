## Verifier correction found by the live run

The first honest run exposed a false negative in the deterministic verifier.
Gemma used a valid recursive `setTimeout` game loop, while the rule recognized
only `setInterval` and `requestAnimationFrame`. The graph therefore made three
unnecessary attempts and stopped even though its final HTML passed the real
browser layer once checked with the corrected rule.

The static rule now accepts all three browser scheduling mechanisms, with a
regression test for recursive `setTimeout`. The original stopped-run artifact
then passed all 10 layered checks in Edge. It remains evidence of diagnosis,
not the closing acceptance run.
