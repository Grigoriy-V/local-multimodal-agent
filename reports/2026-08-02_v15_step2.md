# Version 1.5 step 2 — governed capability registry

**Date:** 2026-08-02  
**Result:** passed

## Product behavior

- One `CapabilityGrant` binds an allowed root and named capabilities.
- `CapabilityRegistry` exposes only tools present in that grant.
- The current app grants `filesystem.read`, `filesystem.write` and
  `browser.inspect` inside `AGENT_WORKSPACE`.
- Writes and edits retain per-call confirmation. Browser inspection creates a
  unique evidence artifact inside `.agent/browser/`; it cannot read outside the
  granted root.
- `inspect_page` is general local-HTML evidence collection, not a task verifier:
  it returns page text, element counts, console errors and a screenshot to the
  model and UI while blocking external network and `file://` requests.
